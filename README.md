# El Roi — Distribución v2

Sitio informativo local para una cafetería ficticia. Esta versión no está publicada.

Abre index.html en tu navegador; para editar abre esta carpeta en Visual Studio Code.

Lee **GUIA-CAMBIOS.md** para completar los textos, fotografías, horario, dirección, Waze y redes. Los SVG son espacios provisionales y deben reemplazarse por tus fotografías antes de publicar.

Estructura: portada, tres beneficios, menú, historia, ubicación y horario, galería horizontal y pie de página. Se conservan los productos de ejemplo y su filtro.

La paleta puede ajustarse desde las variables al principio de css/estilos.css. Las categorías, productos, logo y fotografías quedan para su revisión posterior.

La carpeta original de Descargas se respaldó antes de aplicar esta distribución.
