# Créditos

El Roi es una cafetería ficticia para un proyecto universitario.

- Distribución elaborada a partir de las indicaciones del usuario y sus capturas como referencias de composición. No se copiaron sus marcas, promociones ni direcciones.
- Los archivos SVG de assets/img son espacios gráficos provisionales, creados para la maquetación; no son fotografías de una cafetería real.
- Tipografías: Cormorant Garamond y Manrope, servidas por Google Fonts con alternativas Georgia y Arial.
- Licencias de fuentes: https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt y https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
